Nintendo DS homebrew

Write PHP right on your Nintendo DS.

NDS PHP is a small PHP interpreter for the DS: type code with the stylus, run single statements in the REPL, split programs into several files and make games with graphics, hardware sprites and sound.

Download the ROM nds-php.nds · @ROM_SIZE@ Documentation

Runs on flashcarts, on the DSi/3DS (e.g. TWiLight Menu++) and in emulators such as melonDS. Source code on GitHub.

The ROM

A tiny PHP workstation in one .nds file

Editor, console, interpreter and asset editors – everything runs on the console itself.

After start-up the letters “NDS PHP” rain down as 3D voxels and build the logo, while the touch screen lists your saved programs – one tap and a program is loaded.

The top screen is a real code editor: move the cursor with the d-pad or the arrow keys, type on the touch keyboard, and the code is colour-highlighted and indented for you. Press SCRN for the REPL console, where single statements run immediately and commands like SAVE or LOAD live. START runs the program.

A program can consist of several files: main.php is the entry point, more files come in with require. Tabs switch files, and a file browser shows all programs on the card with a preview. A sprite editor, a sound editor with a piano keyboard and a built-in help page round it off. The interface follows the language of your DS – German or English.

  • PlatformNintendo DS / DSi / 3DS (homebrew)
  • Filends-php.nds · @ROM_SIZE@
  • LanguagePHP dialect with classes, compiled to bytecode
  • ProgramsUp to 16 files, main.php starts
  • Graphics256×192 bitmap, 16 colours
  • Sprites256 images 8×8, 64 hardware objects
  • Sound10 tune slots, tones & ready-made effects
  • StorageA folder per program in /nds-php, data files & JSON
  • Built withdevkitARM · libnds · Docker

Features

Everything you need to code on the go

From the first echo to a little game – without a PC.

</>

Code editor

Edit in place with the cursor, line numbers in the gutter, syntax colours, auto-indent after {. Errors jump to the right file and line.

d-pad RET DEL CLR

>_

REPL console

Run single statements at the > prompt, with history. Variables and functions of the last run stay available.

echo 1+2; RUN SAVE

$

Real PHP

Variables, arrays with keys, functions, closures and arrow functions, classes with interfaces and traits, enums, match, named arguments, exceptions, string interpolation and about 140 built-in functions.

class fn array_map

⧉

Files & browser

Split programs into several files and pull them in with require. Tabs switch files, the file browser previews every program. A debugger stops at breakpoints, steps through lines and shows the variables.

require FILES DBG

◢

Graphics & sprites

A 256×192 pixel layer for lines, boxes and circles, 64 hardware sprites with collision checks and a touch sprite editor.

line() circle() sprite()

♪

Sound & input

Play tunes in on a piano keyboard, play tones and effects from code, save high scores as JSON; read buttons and the touch screen.

sfx() json_encode() touch()

Example

PHP, as you know it

Paint a ball in sprite slot 1, play a beep into sound slot 0 – this program bounces the ball across the screen until you press B. Helpers go into their own file and come in with require.

main.phputil.php
1require "util.php";   // bounce()
2
3$x = 10; $y = 10; $dx = 2; $dy = 1;
4cls();
5echo "HELLO NINTENDO DS!";
6
7while (!(joy() & JOY_B)) {
8  sprite(0, 1, $x, $y, 2);
9  $x += $dx; $y += $dy;
10  $dx = bounce($x, $dx, 240);
11  $dy = bounce($y, $dy, 176);
12  pause(1);
13}

Get started

Three steps to your first RUN

Download the ROM

Get nds-php.nds (@ROM_SIZE@) – it is built from the source code automatically on every commit.

Copy it to your DS

Put it on the SD card of your flashcart or DSi/3DS (TWiLight Menu++) – or open it in melonDS.

Start coding

Programs are saved as folders in /nds-php on the card. In melonDS, enable the DLDI SD emulation to save.
